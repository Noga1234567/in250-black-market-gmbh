## Sicherheitsprobleme melden

Falls Sie eine Sicherheitslücke entdecken, melde sie bitte **nicht** als öffentliches
GitHub Issue, sondern direkt über einen der folgenden Wege:

1. Nutze die **"Report a vulnerability"** Funktion auf GitHub unter dem
   Tab **"Security"** → **"Advisories"**
2. Beschreibe das Problem so detailliert wie möglich:
   - Was ist die Schwachstelle?
   - Wie kann sie reproduziert werden?
   - Welche Auswirkungen hat sie?

## Was passiert nach der Meldung?

- Wir bestätigen den Eingang innerhalb von **48 Stunden**
- Wir analysieren und beheben das Problem so schnell wie möglich
- Nach dem Fix wird ein neuer Release veröffentlicht
---
Wir schätzen jeden Beitrag zur Sicherheit unseres Projekts!
