🔄 Unser Workflow

  • 1. Branch erstellen

    Jede Änderung startet auf einem neuen Feature-Branch: feat/<name>

  • 2. Änderungen committen

    Commits folgen den Conventional Commits: feat:, fix:, docs:, ci:

  • 3. Pull Request erstellen

    Direkte Pushes auf main sind verboten – jede Änderung geht via PR.

  • 4. Review & Merge

    PR wird geprüft und in main gemerged.

🌿 Branch-Übersicht

Branch Zweck
main Stabiler, produktionsreifer Code. Direkte Pushes verboten
feat/<name> Neue Features und Funktionen
fix/<name> Bugfixes
docs/<name> Dokumentationsänderungen
